ข้อเสนอทางเทคนิค

แนวคิดและแนวทางการดำเนินงาน · System Workflow / System Architecture
และเครื่องมือที่ใช้สำหรับการพัฒนาระบบ
โครงการพัฒนาระบบบริหารจัดการความสัมพันธ์นักลงทุนและฐานข้อมูลกลาง
(CRM & Database Management System)
หน่วยงานผู้ว่าจ้าง: สำนักงานคณะกรรมการนโยบายเขตพัฒนาพิเศษภาคตะวันออก (สกพอ.)
ผู้ยื่นข้อเสนอ: บริษัท ร็อคเก็ต อินโนเวชั่น จำกัด
ใช้ยื่นเป็นเอกสารส่วนที่ ๒ — เอกสารที่หน่วยงานกำหนดเพิ่มเติม
ตามเอกสารประกวดราคา ข้อ (๔) และเกณฑ์คะแนน ภาคผนวก ก ข้อ ๒.๑

ขอบเขตเอกสารฉบับนี้

เอกสารฉบับนี้นำเสนอแนวคิด แนวทางการดำเนินงานแต่ละขั้นตอน เทคนิคของวิธีการพัฒนาระบบ สถาปัตยกรรมระบบ (System Architecture) กระบวนการทำงานของระบบ (System Workflow) เครื่องมือที่ใช้สำหรับการพัฒนา แผนการส่งมอบ และการปฏิบัติการสนับสนุน สำหรับโครงการระบบบริหารจัดการความสัมพันธ์นักลงทุนและฐานข้อมูลกลางของ สกพอ.

สารบัญโดยสังเขป

ลำดับ หัวข้อ เนื้อหาหลัก
1 แนะนำบริษัทและสรุปผู้บริหาร ความเหมาะสมของผู้ยื่นข้อเสนอ และภาพรวมจากสถานะปัจจุบันสู่ระบบที่เสนอ
2 บริบทการปฏิบัติงานและรูปแบบการส่งมอบ Centralized Intelligence · โมเดล Hybrid · ขั้นตอนดำเนินงาน
3 สถาปัตยกรรมและการออกแบบทางเทคนิค Logical / Deployment Architecture · ฐานข้อมูล · ความมั่นคงของ Stack
4 ความสามารถหลักของระบบ (Core features) Master Data · งานภาคสนาม · Investment Journey · Dashboard · SSO/OSS · ความมั่นคง · การโอนย้ายข้อมูล
5 แผนการส่งมอบและการปฏิบัติการ ไทม์ไลน์ ๒๑๐ วัน · UAT / Security · อบรม · การรับประกันและการสนับสนุน
