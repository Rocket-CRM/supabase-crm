## Selection notes

- Prefer **lead** proofs whose stretch framing matches the bid category (e.g. Syngenta + Future Park for B2B / multi-party CRM).
- Others remain valid **count** evidence when TOR requires N contracts above a value floor and accepts CRM/work-tracking generally.
- If nothing stretchable fits hard gates → say so in `manual-requests.md`; do not invent contracts.
