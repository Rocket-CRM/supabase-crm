1. วัตถุประสงค์
บริษัท เคซีจี คอร์ปอเรชั่น จำกัด (มหาชน) (“บริษัทฯ”) มีความประสงค์จะจัดหาผู้ให้บริการระบบ CRM & Loyalty Program เพื่อออกแบบ จัดหา พัฒนา ติดตั้ง เชื่อมต่อระบบ และให้บริการบริหารจัดการ Loyalty Platform สำหรับลูกค้าของบริษัทฯ โดยมีวัตถุประสงค์เพื่อสร้างและบริหารฐานข้อมูลลูกค้า เพิ่ม Customer Engagement และ Customer Loyalty รวมถึงสนับสนุนการทำ Customer Segmentation, Personalized Marketing และ Omnichannel Customer Experience
ระบบที่จัดหาจะต้องสามารถรองรับการเก็บข้อมูลสมาชิกและ Transaction จากช่องทาง Offline และ Online รวมถึงสามารถเชื่อมต่อกับระบบและช่องทางการขายต่าง ๆ ของบริษัทฯ เพื่อให้ข้อมูลลูกค้าและข้อมูลการซื้อสามารถนำมาใช้ในการบริหาร Loyalty Program ได้อย่างมีประสิทธิภาพ
วัตถุประสงค์หลักของโครงการ ได้แก่
1.1 เพื่อจัดทำฐานข้อมูลลูกค้าและ First-party Customer Data ของบริษัทฯ
1.2 เพื่อสร้างและบริหาร Loyalty Program ภายใต้แบรนด์ KCG
1.3 เพื่อเพิ่ม Customer Engagement, Customer Retention และ Customer Loyalty
1.4 เพื่อเพิ่มความถี่ในการซื้อและ Customer Lifetime Value
1.5 เพื่อรองรับการสะสมคะแนน การแลกคะแนน Coupon และ Privilege ต่าง ๆ
1.6 เพื่อรองรับ Customer Segmentation และ Personalized Campaign
1.7 เพื่อรองรับการทำ CRM Campaign และ Mission ทั้งแบบ Basic และ Advanced
1.8 เพื่อเชื่อมต่อข้อมูลจากช่องทาง Offline และ Online เข้าสู่ระบบ Loyalty Platform กลาง
1.9 เพื่อให้บริษัทฯ สามารถวิเคราะห์ Customer Behavior และ Customer Journey เพื่อนำไปใช้ในการวางแผนทางการตลาด
1.10 เพื่อรองรับการขยายระบบและช่องทางการใช้งานในอนาคต

2. คุณสมบัติของผู้มีสิทธิเสนอราคา
2.1 ผู้เสนอราคาต้องเป็นนิติบุคคลที่จดทะเบียนถูกต้องตามกฎหมายในประเทศไทย และมีวัตถุประสงค์ในการประกอบธุรกิจด้าน Software, CRM, Loyalty Platform, Digital Technology หรือธุรกิจที่เกี่ยวข้อง
2.2 ผู้เสนอราคาต้องมีประสบการณ์ในการให้บริการ CRM หรือ Loyalty Program และสามารถแสดง Customer Reference ที่มีลักษณะงานใกล้เคียงกับโครงการนี้ได้
2.3 ผู้เสนอราคาต้องมีบุคลากรที่มีความรู้ ความสามารถ และประสบการณ์เพียงพอสำหรับการดำเนินโครงการ ตั้งแต่การออกแบบระบบ การ Integration การ Implement การทดสอบระบบ และการให้บริการหลังการ Go-live
2.4 ผู้เสนอราคาต้องสามารถดำเนินการเชื่อมต่อระบบกับระบบภายนอกผ่าน API หรือ Integration Method ที่เหมาะสม และต้องมีความสามารถในการรองรับการเชื่อมต่อกับระบบของบริษัทฯ
2.5 ผู้เสนอราคาต้องมีมาตรฐานด้าน Information Security และสามารถปฏิบัติตามข้อกำหนดด้านการคุ้มครองข้อมูลส่วนบุคคล (PDPA) ของประเทศไทย
2.6 ผู้เสนอราคาต้องสามารถเปิดเผยข้อมูล Certificate หรือมาตรฐานด้าน Information Security ที่เกี่ยวข้อง เช่น ISO 27001 หรือมาตรฐานอื่นที่เทียบเท่า
2.7 ผู้เสนอราคาต้องเปิดเผยข้อมูลอย่างครบถ้วน หากมีกรณีที่อาจก่อให้เกิดผลประโยชน์ทับซ้อนกับบริษัทฯ พนักงาน กรรมการ หรือผู้บริหารของบริษัทฯ
2.8 ผู้เสนอราคาต้องสามารถให้บริการและสนับสนุนระบบตลอดระยะเวลาของสัญญา รวมถึงการแก้ไขปัญหาและการบำรุงรักษาระบบตาม SLA ที่กำหนด

3. ขอบเขตหน้าที่และความรับผิดชอบของผู้เสนอราคา
3.1 การจัดหาและติดตั้งระบบ
ผู้เสนอราคาต้องจัดหาและ Implement ระบบ CRM & Loyalty Platform ให้สามารถใช้งานได้ตาม Business Requirement ของบริษัทฯ และต้องดำเนินการตั้งค่าระบบ ทดสอบระบบ และเตรียมความพร้อมก่อน Go-live
3.2 การรองรับจำนวนสมาชิก
ระบบต้องสามารถรองรับสมาชิกได้ไม่น้อยกว่า 200,000 Members และสามารถรองรับการขยายจำนวนสมาชิกเพิ่มเติมในอนาคตได้
3.3 การรองรับ Transaction
ระบบต้องสามารถรองรับ Transaction จากทุกช่องทางที่เกี่ยวข้องไม่น้อยกว่า 100,000 Orders ต่อเดือน และต้องสามารถรองรับปริมาณ Transaction ที่เพิ่มขึ้นในอนาคตได้
3.4 Touchpoint
ระบบต้องรองรับการเชื่อมต่อและใช้งานผ่าน Touchpoint ดังต่อไปนี้
	•	LINE Official Account
ทั้งนี้ Website / Shopify จะเป็น Future Integration ตามแผนการดำเนินงานของบริษัทฯ

4.3 Member Tier
ระบบต้องรองรับการแบ่งสมาชิกเป็น Tier และสามารถกำหนดเงื่อนไขของแต่ละ Tier ได้ เช่น

	•	Purchase Frequency
	•	Transaction
	•	Customer Behavior
	•	Campaign Participation
บริษัทฯ ต้องสามารถกำหนดสิทธิประโยชน์และ Campaign ที่แตกต่างกันในแต่ละ Tier ได้
จำนวน Tier และเงื่อนไขของแต่ละ Tier จะถูกกำหนดร่วมกันระหว่างบริษัทฯ และผู้ให้บริการในช่วง Implementation

22. หลักประกันการปฏิบัติตามสัญญา
ผู้เสนอราคาที่ได้รับการคัดเลือกจะต้องวางหลักประกันการปฏิบัติตามสัญญาในอัตราร้อยละ 5 ของมูลค่าสัญญาทั้งหมด หรือเป็นไปตามเงื่อนไขและระเบียบของบริษัทฯ

23. เงื่อนไขการเปลี่ยนแปลงขอบเขตงาน
บริษัทฯ ขอสงวนสิทธิ์ในการปรับเปลี่ยนรายละเอียดของระบบ Feature, Integration หรือขอบเขตการให้บริการตามความจำเป็นทางธุรกิจ โดยจะแจ้งให้ผู้เสนอราคาทราบและดำเนินการตามกระบวนการ Change Request ที่ตกลงร่วมกัน
กรณีการเปลี่ยนแปลงดังกล่าวมีผลกระทบต่อค่าใช้จ่ายหรือระยะเวลา ผู้เสนอราคาต้องเสนอรายละเอียดผลกระทบและค่าใช้จ่ายให้บริษัทฯ พิจารณาและอนุมัติก่อนดำเนินการ

24. สิทธิในการพิจารณาข้อเสนอ
บริษัทฯ ขอสงวนสิทธิ์ในการพิจารณาคัดเลือกเฉพาะผู้เสนอราคาที่สามารถปฏิบัติตามเงื่อนไขและข้อกำหนดที่ระบุใน TOR ฉบับนี้ได้ครบถ้วน
ในกรณีที่ผู้เสนอราคารายใดจัดส่งข้อมูลหรือเอกสารไม่ครบถ้วน ไม่ถูกต้อง หรือไม่เป็นไปตามข้อกำหนด บริษัทฯ มีสิทธิไม่รับพิจารณาข้อเสนอของผู้เสนอราคารายนั้น โดยผู้เสนอราคาไม่มีสิทธิเรียกร้องค่าเสียหายใด ๆ จากบริษัทฯ
การพิจารณาและตัดสินของบริษัทฯ ให้ถือเป็นที่สุด

26. กำหนดยืนราคา
ผู้เสนอราคาจะต้องกำหนดยืนราคาไม่น้อยกว่า 60 (หกสิบ) วัน นับถัดจากวันที่ยื่นเสนอราคาเป็นต้นไป
ตลอดระยะเวลาดังกล่าว ผู้เสนอราคามีหน้าที่ต้องคงไว้ซึ่งราคาที่ได้เสนอ และไม่สามารถเพิกถอน แก้ไข เปลี่ยนแปลง หรือยกเลิกการเสนอราคาของตนได้ เว้นแต่ได้รับความยินยอมเป็นลายลักษณ์อักษรจากบริษัทฯ

27. การชำระเงินค่าบริการ
บริษัทฯ จะชำระค่าบริการให้แก่ผู้เสนอราคาที่ได้รับการคัดเลือกตามเงื่อนไขที่ระบุไว้ในสัญญา โดยการชำระเงินจะดำเนินการภายหลังจากผู้เสนอราคาได้ส่งมอบงานประจำงวดครบถ้วน ถูกต้อง และบริษัทฯ ได้ตรวจรับงานเรียบร้อยแล้ว
การวางบิลและการชำระเงินให้เป็นไปตามระเบียบการรับวางบิลและการจ่ายชำระเงินของบริษัทฯ ที่มีผลใช้บังคับ ณ ขณะนั้น

28. ระยะเวลาการดำเนินโครงการ
ระยะเวลาการดำเนินโครงการกำหนดตั้งแต่เดือน พฤศจิกายน 2569 ถึงเดือนมกราคม 2570 และมีกำหนด Go-live วันที่ 1 มกราคม 2570
บริษัทฯ ขอสงวนสิทธิ์ในการประเมินผลการดำเนินงานของผู้เสนอราคาในช่วง Implementation และ Post Go-live โดยครอบคลุมถึงคุณภาพของระบบ ความครบถ้วนของ Function การ Integration ความสามารถในการรองรับปริมาณข้อมูล การให้บริการ และการปฏิบัติตาม SLA
หากผลการดำเนินงานไม่เป็นไปตามมาตรฐานหรือเงื่อนไขที่บริษัทฯ กำหนด บริษัทฯ มีสิทธิ์ดำเนินการตามเงื่อนไขของสัญญา
